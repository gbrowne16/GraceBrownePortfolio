# NYC Public WiFi Finder

A web application that finds the nearest public WiFi location in New York City based on a user's latitude and longitude.

## About the Project

This project was created as part of the AP Computer Science Principles Exam. It uses a dataset of public WiFi locations throughout New York City and compares geographic coordinates to determine which WiFi location is closest to the coordinates entered by the user.

## How It Works

1. The user enters a longitude and latitude.
2. JavaScript reads location information from a public WiFi dataset.
3. The program calculates the distance between the entered coordinates and available WiFi locations.
4. The closest public WiFi address is displayed on the webpage.
