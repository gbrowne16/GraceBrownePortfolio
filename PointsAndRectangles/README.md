# Points and Rectangles

A Java project that uses object-oriented programming to represent points and rectangles and perform geometric calculations.

## About the Project

This project explores object-oriented programming by creating custom classes for geometric objects. Points are represented using coordinates, while rectangles are constructed and manipulated using those points and their dimensions.

The project separates functionality across multiple classes to demonstrate how objects can interact within a larger program.

## Classes

### Point
Represents a point using coordinate values.

### Rectangle
Represents a rectangle and contains methods for working with its geometric properties.

### Canvas
Provides functionality for displaying or working with the geometric objects.

### Main
Creates and tests objects from the other classes.
