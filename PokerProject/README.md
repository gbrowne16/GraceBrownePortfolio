# Poker Project

A Java project that models a card game while applying object-oriented programming concepts.

## About the Project

This project uses Java classes and graphical card assets to represent the components and logic of a card game. It was designed to strengthen my understanding of larger programs in which multiple objects and classes work together.

The project also incorporates image assets for individual playing cards, connecting the underlying Java logic with a visual representation of the game.

## Technologies

- Java
- Object-Oriented Programming
- Image Assets

## Concepts Demonstrated

- Classes and objects
- Methods
- Conditional logic
- Loops
- Collections of objects
- Program organization
- Game-state logic
- Working with graphical assets
