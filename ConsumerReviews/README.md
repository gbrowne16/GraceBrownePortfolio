# Consumer Review Sentiment Analysis

A Java program that analyzes the sentiment of consumer reviews using individual word sentiment values.

## About the Project

This project explores how computers can analyze written reviews and estimate whether the language used is positive or negative. The program processes text files containing consumer reviews and compares words against sentiment data.

It can calculate an overall sentiment score and use that information to analyze the tone of a review.

## Features

- Reads consumer reviews from text files
- Processes individual words within reviews
- Assigns sentiment values to words
- Calculates total review sentiment
- Estimates ratings based on sentiment
- Manipulates review text using sentiment information
